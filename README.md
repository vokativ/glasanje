# Корак до гласа — избори 2026.

**Корак до гласа** је независан, отворен алат који помаже држављанима Србије у иностранству да попуне актуелни званични захтев за гласање из иностранства.

**[Отворите апликацију на korakdoglasa.org](https://korakdoglasa.org/)**

Апликација се објављује на Firebase Hosting-у. GitHub Pages је искључен; опис пројекта и упутства одржавамо у овом README-у и фасцикли `docs/`.

Не прима гласове, не подноси захтев уместо вас и није сајт државног органа. Помаже да документ припремите на свом уређају и пошаљете надлежном дипломатско-конзуларном представништву.

## Зашто постоји

Пријава за гласање из иностранства је годинама значила: пронађите надлежну мисију, пронађите образац и адресу за контакт, одштампајте, попуните, потпишите, скенирајте и на крају пошаљите све прилоге без сигурности да сте нешто пропустили.

Овај алат постоји да тај технички део буде једноставнији. Људи у амбасадама и конзулатима треба да приме исправан захтев; грађанима у дијаспори треба јасан пут до њега.

Пројекат наставља идеју решења које је 2017. започео Богдан Ђукић: [glasajDijasporo](https://github.com/bdjukic/glasajDijasporo).

## Шта вас чека

1. Проверите да ли сте уписани у [Јединствени бирачки списак](https://upit.birackispisak.gov.rs/).
2. Унесите податке из српског документа, укључујући име једног родитеља.
3. Изаберите државу боравка и надлежно представништво.
4. Потпишите се на екрану или изаберите штампање и својеручни потпис.
5. По жељи додајте слику пасоша или личне карте; алат је ставља као другу страну PDF-а.
6. Преузмите PDF или га поделите са својом апликацијом за е-пошту, па сами проверите примаоца, прилоге и пошаљите поруку.

Страница статуса адреса приказује све државе по словима, са заставицама и ознакама потпуне, делимичне или непотврђене покривености изборним адресама. Отворите државу да видите контакте и обавештења свих њених представништава. Ако одатле започнете пријаву, она се отвара одмах на уносу личних података, са сачуваним избором државе и писма. На завршном екрану је подсетник за проверу бирачког списка. За мисију без потврђене изборне адресе можете отворити припремљен упит у својој апликацији за е-пошту: порука наводи државу боравка, пита за упутство и адресу за предају и подсећа на рок за пријаву. Поруку прегледате и шаљете сами.

## Шта остаје на вама

- **Проверите адресу мисије.** Приказани контакт је преузет са јавно објављене странице МСП/мисије, али није нужно потврђено изборно сандуче. Упоредите га са обавештењем мисије за изборе 2026.
- **Пошаљите захтев сами.** Алат не може да потврди да је порука послата или примљена. Сачувајте копију послате поруке и тражите потврду пријема.
- **Приложите документ.** Ако слика пасоша или личне карте није уграђена у PDF, приложите је ручно пре слања.
- **Ако нисте у Јединственом бирачком списку (ЈБС),** овај алат попуњава само актуелни захтев за гласање у иностранству. За упис у ЈБС потребан је одговарајући засебан званични поступак.

Правни основ за овај захтев је члан 16. Закона о јединственом бирачком списку. За општи праг и изузетке при отварању бирачких места погледајте [члан 57. Закона о избору народних посланика](https://www.pravno-informacioni-sistem.rs/SlGlasnikPortal/eli/rep/sgrs/skupstina/zakon/2022/14/2/reg); званични правни портал може спорије да се учита.

## Подаци остају на вашем уређају

Име и презиме, име једног родитеља, ЈМБГ, адресе, потпис и слика документа обрађују се у прегледачу да би се направио PDF. Алат нема базу личних података и не шаље захтев уместо вас.

Можете проверити ову тврдњу:

- отворите алат и погледајте мрежне захтеве у прегледачу;
- сачекајте да дијалог приватности прикаже да је припрема за рад без интернета завршена, затим искључите интернет и попуните/генеришите PDF у истој отвореној страници;
- прегледајте отворени изворни код.

Када изричито отворите дељење или своју апликацију за е-пошту, PDF и текст поруке прелазе у системску или мејл апликацију коју сте изабрали. Тада важе правила приватности тог провајдера.

## Шта други грађански алати могу да преузму

Ово решење је намерно једноставно и преносиво:

- користи актуелни званични образац уместо измишљања новог;
- PDF попуњава локално, са уграђеним фонтом за ћирилицу;
- користи Web Share само ако прегледач заиста уме да дели фајлове;
- не обећава да `mailto:` може да приложи фајл или пошаље поруку;
- одваја јавно прикупљене контакте мисија од ручно проверених изборних адреса.

Код је под MIT лиценцом. Корисно је копирати образац и прилагодити га другом јавном поступку, али увек проверите локална правила, званични образац и адресу примаоца.

## Подаци о мисијама

Јавни адресар обухвата амбасаде, конзулате и нерезиденцијалну покривеност. Освежава се из јавно објављених страница Министарства спољних послова.

Поступак за изборне примаоце је ограничени, извором поткрепљен ток: подразумевана команда открива кандидате, извози јавне пакете и прави dry-run без креденцијала и без измене override-а. Један стваран AI преглед са цитатима ауторизује недвосмислено нови налаз; архитекта се укључује само за стварну неизвесност или сукоб. Покрените `bun run contacts:run -- --election-id 2026-parliamentary`; пуни циклус је засебни, изричит `bun run contacts:full -- --election-id 2026-parliamentary`. Детаљи о атестираном harness увозу, промоцији и траговима су у [оперативном упутству](docs/election-contact-operations.md). Не мењајте ручно генерисани `src/data/missions.ts`.

### Потребни алати на новом рачунару

Клонирање репозиторијума не инсталира развојне алате. Пре `bun install` инсталирајте:

- **Bun** за зависности, команде и тестове. Проверено са Bun 1.4.0. Пратите [званично упутство за инсталацију](https://bun.sh/docs/installation); ако већ имате npm, можете користити `npm install -g bun`. Отворите нови терминал и проверите `bun --version`. Ако команда није пронађена, проверите да је Bun директоријум у `PATH` према том упутству.
- **Node.js** за Vite команде: инсталирана верзија Vite захтева Node 20.19+ у грани 20 или 22.12+. Проверено са Node 22.22.1; проверите `node --version`.
- **Python 3** за `build:data`, прикупљање контаката и Python тестове. Проверено са Python 3.14.4; проверите `python3 --version`.

За прикупљање контаката потребни су и Python пакети `beautifulsoup4` (HTML) и `pypdf` (PDF текст). Инсталирајте их у виртуелно окружење и активирајте га пре Python/Bun команди које покрећу прикупљање:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install beautifulsoup4 pypdf
```

На Windows-у активација у PowerShell-у је `.venv\Scripts\Activate.ps1`; за постојеће скрипте обезбедите и команду `python3` (или користите WSL). Само `build:data` користи Python стандардну библиотеку. За одржаваочево објављивање потребан је и Firebase CLI (`firebase --version`) са приступом одговарајућем пројекту; није потребан за локални развој.

После инсталације алата, из корена клонираног репозиторијума:

```bash
bun install --frozen-lockfile
bun run dev
bun run check
bun test
bun run build
```

За освежавање јавних података о мисијама:

```bash
bun run scrape:mfa
bun run build:data
python3 -m unittest tests/test_election_contact_pipeline.py
```

Продукционо објављивање је поступак одржаваоца пројекта и користи приватно чуван ID хостинг пројекта. Сарадници могу направити сопствену статичку инстанцу, али не треба да објављују продукцију овог пројекта.
