# Корак до гласа — Избори 2026.

Бесплатан, безбедан и отворен веб алат за српску дијаспору широм света који олакшава припрему и подношење пријаве за гласање из иностранства.


## 🏛️ Правни основ и контекст (Избори 2026)

Ванредни парламентарни избори у Републици Србији расписани су 9. септембра 2026. године за **25. октобар 2026. године**.

Према **члану 16. став 1. Закона о Јединственом бирачком списку** („Сл. гласник РС“, бр. 104/2009 и 99/2011), бирачи који бораве у иностранству могу преко дипломатско-конзуларног представништва Републике Србије поднети:
> **Захтев за упис у бирачки списак податка да ће бирач гласати у иностранству**

Захтев се подноси најкасније пет дана пре дана закључења јединственог бирачког списка (оквирно почетак октобра 2026. године).

## 🚀 Нова парадигма и унапређења у верзији 2026

У претходним верзијама (2020–2022) корисници су морали да преузму PDF, ручно пронађу скинути фајл, сликају пасош, отворе `mailto:` линк (који у прегледачима не може аутоматски да прикачи фајлове) и ручно додају оба прилога.

У верзији 2026. систем је потпуно модернизован:

1. **Web Share API са прикаченим PDF-ом:**
   - На подржаним мобилним уређајима (iOS Safari, Android Chrome), клик на дугме за дељење отвара системски мени са **аутоматски прикаченим потписаним PDF-ом** директно у Apple Mail, Gmail или Outlook апликацији.
2. **Све у једном документу (Опциона страна 2):**
   - Корисник може директно у прегледачу сликати или учитати пасош/личну карту. Алат слику аутоматски спаја као **другу страну истог PDF-а**. На тај начин шаље се само један комплетан фајл!
3. **Брзи линкови за веб-мејл и копирање:**
   - Један клик за копирање објављеног контакта амбасаде или конзулата.
   - Један клик за копирање готовог текста пријаве.
   - Директни дугмићи за отварање форме за слање у **Gmail-у**, **Outlook-у**, **Yahoo-у** и подразумеваном мејл клијенту (`mailto:`).
   - Контакти су преузети са тренутно објављених страница мисија/МСП и нису нужно потврђени мејл-сандучићи за изборне пријаве. Пре слања проверите обавештење за изборе 2026. на линку ка званичном сајту мисије.
4. **Комплетан адресар Министарства спољних послова (195 држава):**
   - Укључује све амбасаде и генералне конзулате.
   - Аутоматски мапира нерезиденцијалну покривеност (нпр. грађани у Сингапуру добијају Амбасаду у Џакарти, грађани у Ирској Амбасаду у Лондону, грађани на Новом Зеланду Амбасаду у Канбери итд.).
   - Приказује линк ка званичном веб-сајту сваке амбасаде.
5. **Глатки дигитални потпис (Bézier curves) и опција штампе:**
   - Модеран `signature_pad` v5 са подршком за високу резолуцију екрана и брисање.
   - Опција „Потписаћу ручно на папиру“ за оне који желе да одштампају образац и потпишу га оловком.

## 🔒 Приватност података — 100% локално

Ова апликација је пројектована по принципу **нула знања (zero-knowledge / local-first)**:
- **Ниједан лични податак не напушта ваш уређај.** Име, презиме, ЈМБГ, адреса, потпис и слика пасоша се обрађују искључиво у меморији вашег прегледача.
- **Не постоји серверска база нити бекенд АПИ.** Све се извршава на клијентској страни.
- **Ради и без интернета:** Након што отворите сајт, можете искључити интернет (авио-режим) и у потпуности попунити, потписати и генерисати свој PDF формулар.

## 🛠️ Технологије и покретање пројекта

Апликација је мигрирана са застарелог Angular 9 стека на модеран, брз и лаган стек:
- **Vite 6 + React 18 + TypeScript 5.7**
- **pdf-lib + fontkit** за векторско генерисање PDF-а и уграђивање ћириличног Roboto фонта
- **signature_pad 5** за глатко цртање потписа
- **Bun** као брзи JS runtime и пакет менаџер

### Инсталација и локални развој

```bash
# Инсталација зависности
bun install  # или npm install

# Покретање развојног сервера (localhost:3000)
bun run dev

# Провера типова и компајлирање продукционе верзије (dist/glasanje)
bun run build

# Покретање аутоматских тестова
bun test
```

### Ажурирање података о дипломатским представништвима

У директоријуму `scripts/` налазе се скрипте за преузимање и обраду званичних података са сајта Министарства спољних послова:

```bash
# 1. Скрејповање података са mfa.gov.rs
bun run scrape:mfa

# 2. Нормализација и генерисање src/data/missions.ts
bun run build:data
```

За безбедан оперативни поступак откривања, AI саветодавног прегледа и двоструког људског одобравања изборних адреса погледајте [оперативно упутство за изборне контакте](docs/election-contact-operations.md).
